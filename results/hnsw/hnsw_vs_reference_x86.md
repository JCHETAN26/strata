# Strata HNSW vs hnswlib and FAISS: recall@10 vs QPS

Generated by `bench/run_hnsw_curves.py`. Do not edit by hand.

- **Hardware:** AWS c7i.8xlarge (Intel(R) Xeon(R) Platinum 8488C, 16 physical cores x 2 threads, 61.8 GiB, us-east-2a), kernel 7.0.0-1013-aws
- Build: M=16, ef_construction=200, single thread for build and search. Strata uses the paper's neighbor-selection heuristic.
- 5 runs per point, mean ± stdev. Recall is tie-aware recall@10 against exact ground truth.
- Strata QPS is measured in C++; hnswlib and FAISS QPS come from one batched Python call over all queries (Python overhead amortized away). See `bench/run_reference_bench.py`.
- Commits: faiss run at 8ae9bf4dd5; hnswlib run at 8ae9bf4dd5; strata run at 8ae9bf4dd5

**Like for like (the primary comparison):** all three run 256-bit SIMD. Strata uses its AVX2 + FMA kernels; FAISS is held to AVX2 (`FAISS_SIMD_LEVEL` and `SIMDConfig.set_level`); hnswlib is built with `-mavx2 -mfma` instead of `-march=native`, so it has no AVX-512 path. Each run verifies this (`bench/simd_info.py`) and refuses to run otherwise.
