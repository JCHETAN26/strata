# Strata HNSW vs hnswlib and FAISS: recall@10 vs QPS

Generated by `bench/run_hnsw_curves.py`. Do not edit by hand.

- **Hardware:** Apple M2 (fanless development machine): recall is valid; QPS is indicative only. Final speed comparisons run on dedicated hardware (Phase 9).
- Build: M=16, ef_construction=200, single thread for build and search. Strata uses the paper's neighbor-selection heuristic.
- 3 runs per point, mean ± stdev. Recall is tie-aware recall@10 against exact ground truth.
- Strata QPS is measured in C++; hnswlib and FAISS QPS come from one batched Python call over all queries (Python overhead amortized away). See `bench/run_reference_bench.py`.
- **The hnswlib speed comparison favors Strata on ARM:** hnswlib's distance code has no NEON path (its SIMD is SSE/AVX only), so here it computes distances in scalar code while Strata and FAISS use NEON. Fair speed comparisons against both libraries come from the x86 runs in Phase 9.
- Commits: faiss run at 72c148ecfa; hnswlib run at 72c148ecfa; strata run at 72c148ecfa
